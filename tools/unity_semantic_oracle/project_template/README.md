# VAPB Oracle project template

This public template describes the isolated Unity 2022.3 project layout used
for human Oracle runs. Copy the authored files from the sibling `Assets/Editor`
directory into `Assets/Editor/VAPB` when creating another isolated instance.
The ready-to-open local instance is documented in `README_VAPB_ORACLE.md`.

Do not add Library, Temp, Logs, UserSettings, commercial packages, or raw
Oracle output to Git.

# Version Semantics Matrix

| Surface | Unity 2022.3 | Unity 6 |
|---|---|---|
| Access | human-started Editor runner | official Unity MCP only |
| Current status | runner available; harvest pending | MCP unavailable in current connector set |
| API rule | documented public Editor APIs | documented public APIs through official route |
| Comparison | declared semantic fields | declared semantic fields |

Version-specific unsupported fields are recorded as limitations. They are not
silently treated as equal.

# Corpus Matrix

The target matrix is 23 packages, 7 groups, approximately 145 prefabs, 44 FBX,
365 materials, and 647 textures, subject to remeasurement by the human-run
Oracle. Public output records only aggregate counts and synthetic case IDs.

Holdout is by package group, not by individual asset. Candidate order,
filename, GUID order, and object-name permutations must be included in the
synthetic invariance suite. The current repository contains no commercial
corpus payload or raw corpus JSON.
